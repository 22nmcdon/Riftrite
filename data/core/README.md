# data/core/

The shared rules every fight uses: the tuning numbers (`tuning.json`: the grid, unit sizes, Rift Collapse, the chain limit), the statuses more than one hero or the enemies use (`statuses.json`; a hero's own are in its folder), and the tactics (`tactics.json`, which the loadout's tactic items name).

## Files

| File | What it is |
| --- | --- |
| `statuses.json` | Strongest per stack, fades fast, half as effective against shields. (72 entries) |
| `tactics.json` | Casters are the caster and support archetypes: Cinder Moth and Gloam Witch in Act 1; Act 2 adds the summoner, and Act 3 the mimic. (14 entries) |
| `tuning.json` | Starting values for tuning. |
