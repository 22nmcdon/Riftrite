# data/run/items/

The loadout pool, one file per kind: charms, tactics (each names a `data/core/tactics.json` entry), sigils, and gambits, each with three ranks. Any hero holds any item. The rules and prices: `docs/plans/design/loadout/` and each act's `act.json`.
