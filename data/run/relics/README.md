# data/run/relics/

The relic pool, one file per tier. Relics have no downsides and are team-wide; `bond.json` holds the free bond relics a duo bond unlocks (a fifth of the shops' relic draws once it's on). The rules and every decision: `docs/plans/design/relics/`.
