# tests/run/

The run's tests, by topic, and `run_test_kit.gd` (a run's content and states for tests). They drive `RunFlow` one action at a time.

## Folders

| Folder | What it holds |
| --- | --- |
| `days/` | A day and the run around it: the flow, the new day's loop, camp, events and oaths, Rift Tear, the Shrine, the Magpie, acts, and endless. |
| `draws/` | The run's seeded draws: the streams, the testing shop lean, specializations, enemy upgrades, what the rift learns, and the team draft. |
| `rewards/` | What a run earns and spends: the economy, relics, the loadout, growing cards, the upgrade pools, apexes and their cards, Tithe, and transmuting. |

## Files

| File | What it is |
| --- | --- |
| `run_test_kit.gd` | Small helpers for driving a RunFlow through the day's order in tests. |
