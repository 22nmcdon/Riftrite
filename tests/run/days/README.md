# tests/run/days/

A day and the run around it: the flow, the new day's loop, camp, events and oaths, Rift Tear, the Shrine, the Magpie, acts, and endless.

## Files

| File | What it is |
| --- | --- |
| `test_acts.gd` | Acts 2 and 3's frame, on a stand-in content set: Act 2 and Act 3 draw Act 1's fights, and Act 3 has real endless. |
| `test_camp.gd` | Camp, relics, and duo bonds in a run: places and their options, each option's one job, the next fight's modifiers, relic choices and relics' rules, and bonds. |
| `test_endless.gd` | Endless after Act 1: the choice after the act's boss shop, floors as days, rift modifiers gathered every 3 floors, the collapse and crumbled ground, the shops' legendaries, boss relics then legendaries, the first loss ending the run, the save, and the... |
| `test_events.gd` | The Event node: the scenes and every choice's results, greyed choices, walking away, the Bloodied Oath and each oath's burden, reward, and end, the nodes a day shows, and the save. |
| `test_magpie.gd` | The Magpie's stall: two charms at rank II, a relic at 25% off, buying relics, and one swap a visit. |
| `test_new_day.gd` | The new day: the route, the fight, after it, the Pedlar after every fight, then a node; the boss's day; a loss replaying the day with the node's setup held; the node draw; and the save. |
| `test_rift_tear.gd` | A Rift Tear's depths and the rift modifiers: choosing a depth, the day's modifiers, each modifier on tomorrow's fight, each depth's relics, and Early Collapse and Reinforcements in a fight. |
| `test_run_flow.gd` | The run layer: the act draw, starting a run, the day's actions and their order, winning, losing and replays, wounds and deeds, saving and loading, and the simple run bot. |
| `test_shrine.gd` | The Shrine's offerings: shards or a wound for a rare relic, a relic for one a tier higher; nothing spent until the relic is taken. |
