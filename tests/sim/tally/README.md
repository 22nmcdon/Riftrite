# tests/sim/tally/

The read-only counts over a fight: the chart, the combo readout, and the growth tallies.

## Files

| File | What it is |
| --- | --- |
| `test_combo_tally.gd` | The combo readout's pieces: the damage rule's notes on each number, kept out of the log's text; and ComboTally's fires, chains, and what each engine added, read from the chaos fight's log. |
| `test_fight_tally.gd` | FightTally: the fight chart's and the sim runner's numbers, added up from the log. |
| `test_tallies.gd` | Tallies: what a hero's growing cards count, the way deeds do, including the kinds and filters step 4 adds. |
