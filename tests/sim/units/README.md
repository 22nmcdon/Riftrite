# tests/sim/units/

Passives' triggers and chains, keywords, deeds, tactics, gambits, copies, habits, and the heroes' rules from relics.

## Files

| File | What it is |
| --- | --- |
| `test_copies.gd` | Copying a signature: the first copyable hero signature becomes the copier's, cast on its own bar with the sides turned; what can't be copied; Greedy, Twinned, and the Queen's court. |
| `test_deeds.gd` | Counting deeds, in tiny fights: each kind counts what it says, each filter keeps out what it should, and counting never changes the fight. |
| `test_gambits.gd` | Gambits: where a gambit lets a hero start, arriving late, swapping places, and the fight-start and arrival passives, with the gambits as the data has them. |
| `test_habits.gd` | Habits: a transformation that replaces a hero's signature keeps the old one as a passive on every Nth basic attack, with the old signature's id. |
| `test_hero_rules.gd` | The heroes' rules, each in a small fight and each shown changing nothing without its rule: Crown of Stars, Shared Pain, The Hungering Rift, Overcharge, Second Dawn, Chain of Echoes, Crown of the Hollow King, Everflame, The Unbending, Riftwalker's Soles,... |
| `test_keywords.gd` | Keywords and conditions: names for a unit's state, one shape for "a unit that is ...", and the auras that use it. |
| `test_tactics.gd` | What each tactic does in a fight, in tiny fights. |
| `test_triggers.gd` | Triggers and the chain guard: the new events, the filters on the built ones, and chains of event effects that stop at the fight's chain_limit. |
