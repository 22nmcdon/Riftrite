# tools/teams/

The teams the reports and bots play: formations by role for the sim runner, the apex report's teams, the builds report's teams, and the test teams (synergy, plan, and bad teams) with their fixed vows.

## Files

| File | What it is |
| --- | --- |
| `apex_teams.json` | Teams for the --apexes report: each names an apex per hero. |
| `build_teams.json` | The builds report's teams. |
| `sim_formations.json` | The sim runner's named formations, by role since the team draft: role -> [col, row] on the heroes' rows 0 to 2. |
| `test_teams.json` | The run report's test teams. |
