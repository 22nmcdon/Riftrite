# tools/reports/

The reports the runners print, as libraries the runners and tests call: the encounter gate, paths and deeds, apexes, builds, and runs.

## Files

| File | What it is |
| --- | --- |
| `apex_report.gd` | The sim runner's apexes report. |
| `build_report.gd` | The sim runner's builds report. |
| `path_report.gd` | The sim runner's paths and deeds reports. |
| `run_report.gd` | The run report: a bot plays many runs, and this measures pacing: runs won and where the rest end, when each hero first transforms, picks per hero, shards earned and spent, wounds taken, relics found, the nodes shown and taken, and how each encounter goes. |
| `sim_report.gd` | The sim runner's work, apart from its command line so a test can run it. |
