# Archive: the design before the rebuild

Everything in this folder is **superseded**. It describes the game before the rebuild (2026-09-27): items, essences and infusions, shops, the Guildhall, ranks, specializations and deeds, two fixed rows of units, and the UI look built for them.

It's kept for history, and as a reference when a rebuild phase brings an old idea back in a new form. The current design is `docs/design.md`, and the rebuild plans are in `docs/plans/rebuild-*.md`.

The code these documents describe was removed in the rebuild's phase 0 (the commit "Rebuild phase 0: gut items, essences, shops, the run, and the old UI"); the commit before it has the whole old game.
