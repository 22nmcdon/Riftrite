# Common relics (25)

**Every shop · 5 shards.** One clean bonus each. Rules for all relics: `README.md`. "Heroes" always means every hero on the team. Numbers are placeholders.

## Stats

| Relic | Effect |
| --- | --- |
| **Whetstone of the Fallen** | Heroes gain +6 ATK |
| **Bloodstone** | Heroes gain +8% ATK |
| **Iron Filings** | Heroes gain +6 DEF |
| **Warden's Chain** | Heroes gain +10% DEF |
| **Hearthstone Shard** | Heroes gain +10% max HP |
| **Quickened Pulse** | Heroes gain +8% attack speed |
| **Bone Dice** | Heroes gain +6 CRIT |
| **Rift Candle** | Heroes with mana gain +1 mana per second |

| Relic | Effect |
