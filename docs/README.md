# docs/

- `design.md`: the game's design, gathered from the plans, and its open questions.
- `plans/`: the plans the rebuild is built from.
- `mockups/`: the playtester's mock of the hero panel and the screens between fights.
- `archive/`: the old game's design, for reference only, never as the design.

## Folders

| Folder | What it holds |
| --- | --- |
| `archive/` | Everything in this folder is **superseded**. |
| `mockups/` | The playtester's mock: the hero panel, the hero bar, the item language, the after-fight pick, the Pedlar, and relic choices. |
| `plans/` | Every plan the rebuild is built from. |
