# src/ui/info/

The sentences and numbers lines the UI shows for kits and cards: `UnitInfo` (heroes and enemies) and `ModInfo` (items, upgrades, relics, bonds), generated from the data.

## Files

| File | What it is |
| --- | --- |
| `mod_info.gd` | The numbers line for a kit mod. |
| `unit_info.gd` | A unit's details for the enemy panel and the hero popup: one line per ability, passive, and trait, each with its sentence and a numbers line under it. |
