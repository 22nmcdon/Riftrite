# art/figures/heroes/

One folder per hero, a figure per form: `base`, one per path (`maren/deadeye`), and one per apex as they're drawn (`maren/hailstorm`; until then an apex stands as its path's form). Kestra's companions (`grit`, `brindle`, `viper`, `nestling`) have folders too, each with its `base`. A figure's key is `heroes/<hero>/<form>` (`FigureArt.key_for`). Placeholders are SVGs from `tools/art/hero_kit.py`; a commissioned PNG of the same name replaces one.
