# art/look-tests/

Style tests: the look of the figures, the arena, the map, the shops, and each act's palette (`act2_look_test`, `act3_look_test`, `acts_side_by_side`, from `tools/art/act_look_tests.py`), and the style as pixel art (`pixel_act1_vs_vector`, `pixel_acts`, `pixel_lineup`, from `tools/art/pixel_look_tests.py`), tried before they were built. Left out of builds (`export_presets.cfg`); nothing in the game loads them.
